# Naming conventions

Naming conventions are also called naming styles or case conventions. This page
describes the formats produced by Case Converter. Word boundaries are shown with
the relevant separator; camel and Pascal case join words without a separator.

| Format        | Example           | Word separator                                          |
|---------------|-------------------|---------------------------------------------------------|
| Camel case    | `myNameIsBond`    | None; first word starts lowercase                       |
| Pascal case   | `MyNameIsBond`    | None; each word starts uppercase                        |
| Snake case    | `my_name_is_bond` | Underscore; lowercase                                   |
| Ada case      | `My_Name_Is_Bond` | Underscore; title case                                  |
| Macro case    | `MY_NAME_IS_BOND` | Underscore; uppercase                                   |
| Kebab case    | `my-name-is-bond` | Hyphen; lowercase                                       |
| Train case    | `My-Name-Is-Bond` | Hyphen; title case                                      |
| Cobol case    | `MY-NAME-IS-BOND` | Hyphen; uppercase                                       |
| Dot notation  | `my.name.is.bond` | Dot; lowercase                                          |
| Lower case    | `my name is bond` | Space; lowercase                                        |
| Title case    | `My Name Is Bond` | Space; title case                                       |
| Upper case    | `MY NAME IS BOND` | Space; uppercase                                        |
| Sentence case | `My name is bond` | Space; first word title case, remaining words lowercase |

Capitalization follows Unicode case-mapping rules.
See [Case mapping](case-mapping.md).
